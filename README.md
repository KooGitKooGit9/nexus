# Nexus — 팀 워크스페이스 & 워크플로우

오로라랩스(가상 회사)를 위한 올인원 협업 도구. 메신저 · 프로젝트 · 캘린더 · 문서 · 드라이브 · 화이트보드 · 자동화 · 전자결재 · OKR · 공지 · 구성원 · AI 어시스턴트를 하나의 앱에 담았습니다.

## 실행

```bash
npm install
npm run dev      # 웹(5199) + API 서버(5200) 동시 실행 → http://localhost:5199
```

- 처음 접속하면 **로그인 화면**에서 구성원을 고릅니다. 다른 브라우저(또는 주소 뒤 `?as=u_fe`)로 다른 사람으로 접속하면 메시지·태스크·결재 등이 **실시간으로 공유**됩니다.
- 데이터는 `server/data/nexus.db`(SQLite), 업로드 파일은 `server/data/uploads/`에 저장됩니다.
- **AI (Gemini)**: `server/.env`에 `GEMINI_API_KEY=키`를 넣고 재시작하면 Nexus AI와 동료 답장이 Gemini로 동작합니다. 모델은 `GEMINI_MODEL`로 변경(기본 `gemini-3.8-flash`). 키가 없으면 기본(규칙 기반) 모드, `GEMINI_API_KEY=mock`이면 네트워크 없이 테스트용 응답.
- 서버 없이 `npm run dev:web`만 실행하면 예전처럼 브라우저 단독 데모로 동작합니다.

프로덕션 빌드: `npm run build` → `dist/`

## 주요 기능

| 영역 | 기능 |
|---|---|
| 메신저 | 채널/DM/그룹 DM, 스레드, 리액션·이모지, 멘션·채널 자동완성, 슬래시 명령어(`/poll` `/task` `/remind` `/huddle` `/giphy` …), 투표, 파일 첨부·드래그앤드롭, 예약 전송, 검색, 저장 항목, 가상 동료 자동 응답, 허들/화상통화 오버레이 |
| 프로젝트 | 칸반(드래그앤드롭), 리스트(일괄 편집), 간트 타임라인, 인사이트 차트, 태스크 상세(서브태스크·댓글·활동 로그), 스프린트 |
| 캘린더 | 일/주/월/일정/팀 뷰, 드래그로 생성·이동·리사이즈, 빈 시간 찾기, 회의실 예약, RSVP, 한국 공휴일, 일정 알림 |
| 문서 & 위키 | 노션식 블록 에디터(`/` 명령, 마크다운 단축키, 드래그 정렬), 페이지 트리, 템플릿, 목차, 공유, 마크다운 내보내기 |
| 드라이브 | 실제 파일 업로드, 그리드/리스트, 다중 선택, 컨텍스트 메뉴, 미리보기, 휴지통 |
| 화이트보드 | 무한 캔버스, 스티키·도형·화살표·펜·텍스트·이미지, 실행취소, 협업자 커서, PNG 내보내기 |
| 자동화 | React Flow 비주얼 워크플로우 빌더, 트리거/조건/액션/지연 노드, 테스트 실행 애니메이션, 실행 기록 |
| 전자결재 | 휴가·경비·구매·출장·권한 신청 마법사, 결재선 빌더, 승인 도장 애니메이션 |
| 목표 & OKR | 회사/팀 목표 정렬 트리, KR 체크인, 진척도 |
| 공지사항 | 커버, 카테고리, 읽음 확인, 리액션, 마크다운 작성기 |
| 구성원 | 디렉터리, 조직도(팬·줌), 근태(출퇴근 타이머), 칭찬 보드, 프로필 |
| 셸 | ⌘K 커맨드 팔레트(전역 검색, 초성 검색), ⌘J Nexus AI(워크스페이스 데이터 기반 답변), 알림 센터, 토스트, 단축키(`?`), 다크/라이트 + 5가지 액센트 테마, 설정 |

## 단축키

- `⌘K` 커맨드 팔레트 · `⌘J` Nexus AI · `[` 사이드바 접기 · `?` 단축키 목록
- `G` → `H/M/P/C/D/F/B/W/A/O/N/U/S` 페이지 이동

## 구조

- `src/app/` 레이아웃, 사이드바, 상단바, 셸(팔레트·알림·AI·토스트)
- `src/components/ui/` 공용 디자인 시스템
- `src/store/` 사용자·알림·UI 전역 상태
- `src/features/<기능>/` 기능별 모듈 (store · seed · search · views · components)

데이터는 localStorage(`nexus:*`)에 저장되며 탭 간 실시간 동기화됩니다. 설정 → 데이터에서 초기화할 수 있습니다.

> 외부 서비스 연동(GitHub, Figma 등)과 이메일 발송은 계정이 필요해 "데모"로 표시됩니다. 접속하지 않은 동료의 답장은 Gemini(키가 없으면 규칙 기반)로 생성됩니다.
