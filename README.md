# Nexus — 팀 워크스페이스 SaaS

메신저 · 프로젝트 · 캘린더 · 문서 · 드라이브 · 화이트보드 · 자동화 · 전자결재 · OKR · 공지 · 구성원 · AI 비서를 하나로 묶은
멀티 워크스페이스 협업 서비스입니다. 회원가입 → 워크스페이스 생성 → 동료 초대 → 요금제(Free/Pro/Business)까지 갖춰져 있습니다.

## 실행 (개발)

```bash
npm install
npm run dev      # 웹(5199) + API 서버(5200) → http://localhost:5199
```

- `/` 랜딩 · `/pricing` 요금제 · `/signup` 가입 · `/login` 로그인 · `/legal/terms`, `/legal/privacy` 약관
- **무료로 시작하기**: 가입 → 새(빈) 워크스페이스 → 초대 링크로 동료 합류. 실제 멤버만 있고 가짜 데이터는 없습니다.
- **로그인 없이 데모 체험**: 24시간짜리 게스트 + 가상 회사 "Aurora Labs" 데모 워크스페이스(가상 동료 자동 답장 포함).
- 데이터: `server/data/nexus.db`(SQLite) + `server/data/uploads/`. 설정은 `server/.env`(`server/.env.example` 참고).
- **AI (Gemini)**: `GEMINI_API_KEY`, `GEMINI_MODEL`(지금은 가장 저렴한 `gemini-3.1-flash-lite`). 워크스페이스별 하루 사용량은 요금제로 제한됩니다.
- **결제**: `TOSS_CLIENT_KEY`/`TOSS_SECRET_KEY`가 있으면 토스페이먼츠 선불 결제(자동 갱신 없음), 없으면 14일 무료 체험만 제공.
- **메일**: `RESEND_API_KEY`/`MAIL_FROM`이 있으면 초대·비밀번호 재설정 메일 발송, 없으면 서버 콘솔에 링크 출력.

## 출시 전에 채울 것

- `src/config/brand.ts` — 서비스명, 도메인, 문의 이메일, 사업자 정보(상호·대표자·사업자등록번호·통신판매업 신고번호·주소·개인정보 보호책임자). 채우기 전까지 약관 페이지에 "초안" 배너가 보입니다.
- 이용약관·개인정보처리방침은 **초안**입니다. 출시 전 법률 검토를 받으세요.
- 배포·환경 변수·백업·출시 체크리스트는 [DEPLOY.md](DEPLOY.md).

## 단축키

- `⌘K` 커맨드 팔레트 · `⌘J` Nexus AI · `[` 사이드바 접기 · `?` 단축키 목록
- `G` → `H/M/P/C/D/F/B/W/A/O/N/U/S` 페이지 이동

## 구조

- `server/` API·WebSocket·SQLite (인증 `auth.mjs`, 스키마 `db.mjs`, 요금제 `plans.mjs`, AI 프록시 `ai.mjs`, 정적 파일 `static.mjs`)
- `src/features/public/` 랜딩·요금제·가입/로그인·초대·온보딩·약관
- `src/lib/` 세션·동기화(`sync.ts`)·API 클라이언트(`api.ts`)·워크스페이스(`workspace.ts`)·빈 워크스페이스 시작 데이터(`starter.ts`)
- `src/app/` 레이아웃, 사이드바(워크스페이스 전환), 상단바, 셸(팔레트·알림·AI·토스트)
- `src/components/ui/` 공용 디자인 시스템
- `src/store/` 사용자·알림·UI 전역 상태
- `src/features/<기능>/` 기능별 모듈 (store · seed · search · views · components)

데이터는 서버(SQLite)가 원본이고, 브라우저 localStorage(`nexus:<store>@<워크스페이스>:<멤버>`)는 캐시입니다. 워크스페이스 간 데이터는 서버에서 완전히 분리됩니다.
